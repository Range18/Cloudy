# Backup Utility to Cloud Storages

## Автор
Арслан Ибрагимов (Range18)

## Название задачи
Утилита резервного копирования файлов на удалённое хранилище

## Описание
Данная утилита предназначена для резервного копирования файлов и каталогов в облачные хранилища. Поддерживается работа минимум с двумя различными облачными сервисами через их API напрямую. Также реализованы функции загрузки, скачивания и листинга файлов.

## Поддерживаемые хранилища
- Google Drive
- Yandex Disk

## Основные фичи
- Загрузка файлов и каталогов в облачные хранилища
- Загрузка файлов из облака на локальное устройство
- Получение списка файлов и папок на облаке
- CLI-интерфейс для управления операциями
- Все изменения отслеживаются и загружаются на выбранный сервер
